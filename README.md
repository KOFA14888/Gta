# Gta lV — «эмулятор GTA 6» (фанатская сборка)

Неофициальное фанатское приложение-шутка под Android: выглядит как эмулятор
PlayStation 5 с игрой **Grand Theft Auto VI** — запуск, экран загрузки
и виртуальный геймпад DualSense поверх видео из этого репозитория.

> Это не продукт Rockstar Games и не настоящий эмулятор. Видео и арт
> принадлежат их правообладателям. Только для личного пользования.

## Что внутри

- **Имя АПК:** `Gta lV` (`com.gtalv.emulator`, версия 1.0.7)
- **Иконка:** официальный кей-арт GTA VI
- **Главный экран:** кей-арт, логотип GTA VI, кнопка **ИГРАТЬ** с неоновой
  подсветкой и плавным запуском
- **Экран загрузки:** фейковая компиляция шейдеров и инициализация ViperEngine
- **Игровой экран:** видео `VID_20261127_010751_579.mp4` (срезана 1 секунда в начале),
  поверх — виртуальный геймпад DualSense (тачпады, стики, D-pad, △○✕□, L1/L2/R1/R2, PS),
  счётчик FPS, чип оружия (R1/L1 переключают), выстрел по ✕/R2, перезарядка по ○,
  достижения-тосты, пауза по ≡ / PS, выход в меню

## Установка

```bash
adb install "dist/Gta-lV.apk"
# либо скинуть APK на телефон и открыть (разрешить установку из неизвестных источников)
```

## Сборка из исходников

```bash
./build.sh   # инструменты подтянутся сами (apktool 2.9.3 + apksigner через npm)
```

Готовый APK: `dist/Gta-lV.apk` (подпись v1+v2+v3, debug-ключ, `resources.arsc` хранится без сжатия и выровнен по 4 байтам — обязательно для Android 11+).

## Структура

- `VID_20261127_010751_579.mp4` — исходное видео
- `emulator/` — apktool-проект (smali-активити с WebView, ресурсы, `assets/www` — весь UI)
- `build.sh` — сборка и подпись
